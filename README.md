# Webprogramozás 1 - Beadandó Feladat
## Készítők: Hüse Imre és Bacsó Máté

Ez a repozitórium a Webprogramozás 1 tantárgy előadás beadandóját tartalmazza. 
A projekt témája: Forma-1 pilóták nyilvántartása és interaktív alkalmazások.

### Megvalósított technológiák:
* HTML, CSS és reszponzív dizájn
* Natív JavaScript (OOJS)
* React.js (SPA, Komponensek, UseState)
* PHP & MySQL Backend (Fetch API hívásokkal)
